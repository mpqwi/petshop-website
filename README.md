#🐾 petshop-website
Website responsivo para petshops, desenvolvido para facilitar a divulgação de serviços, produtos e informações de contato. O projeto foi construído com HTML, CSS e JavaScript, priorizando organização, usabilidade e experiência do usuário.

🚀Funcionalidades:
Página inicial de apresentação
Seção de produtos e serviços
Área de contato 
Layout totalmente responsivo
Design moderno e amigável

🛠️Tecnologias utilizadas
HTML5
CSS3
JavaScript
